# Lift Log

A dead-simple offline lifting and food log for iPhone. It's a PWA (Vite + TypeScript + Preact): add it to the Home Screen from Safari and it works fully offline. All data stays on the phone in IndexedDB; use Settings → Export to back it up.

## Develop

```sh
npm install
npm run dev     # local dev server
npm test        # unit tests (vitest)
npm run build   # type-check + production build into dist/
```

Icons live in `public/` and are generated by `node scripts/make-icons.mjs`.

## Deploy

Pushing to `main` runs `.github/workflows/deploy.yml`, which tests, builds and publishes `dist/` to GitHub Pages at `https://<username>.github.io/lift-log/`. In the repo's Settings → Pages, set Source to "GitHub Actions". If the repo isn't named `lift-log`, change `base` in `vite.config.ts`.
